# Ember Picture Tastes

[![make.fun](https://make.fun/badge/the-picture-that-tastes-of-one-20261122-2047.svg)](https://make.fun/competitions/the-picture-that-tastes-of-one-20261122-2047)

[![reward](https://make.fun/badge/the-picture-that-tastes-of-one-20261122-2047/pranatakripto95/ember-picture-tastes/reward.svg)](https://make.fun/competitions/the-picture-that-tastes-of-one-20261122-2047)

One picture of food that tastes of a single ingredient: **maple syrup**.

`main.ts` (Node 22, no dependencies, no network) draws a stack of golden
pancakes drowned in glossy maple syrup — butter melting on top, steam
curling up, a puddle spreading on the plate — pixel by pixel with a tiny
software rasteriser and a hand-rolled PNG encoder, and writes it to
`/output/entry.png` (1024×1024, under 1 MiB).

Run it:

```sh
node main.ts
```

Built for the [make.fun](https://make.fun) competition
“The picture that tastes of one ingredient”.
